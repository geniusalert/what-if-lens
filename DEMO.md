# Three-minute genuine demo plan

## Before recording

Configure the server key using SETUP.md. Confirm an unfamiliar incline and math expression parse successfully with real Meta requests. Use a clean browser. Open Scientific Lab and its evidence panel. Click Record demo and select the intended browser tab; the browser asks for screen-capture permission. The tool exports a local WebM and stops automatically after three minutes. It records no microphone audio, so record narration separately or use your normal screen recorder for audio.

Do not label sample or manual input as live image interpretation. Do not submit the mocked HTTP tests as proof of model inference.

## Run of show

| Time | Action | Evidence |
|---|---|---|
| 0:00–0:15 | Upload your incline photograph | Real new input, not a canned animation |
| 0:15–0:45 | Show recognized model, quantities and assumptions; correct a value; confirm | Meta trace and validated IR |
| 0:45–1:20 | Run “Make it stop sliding”; compare and undo | Analytic inverse, forward verification, rest threshold |
| 1:20–2:05 | Upload `z = sin(x)*cos(y)`; confirm; double x frequency | Safe AST, recomputed mesh and numerical gradients |
| 2:05–2:30 | Show the circuit; open switch and change a resistor | Current/power and flow both respond |
| 2:30–3:00 | Open evidence, seek, export, explain scope | Deterministic frames, source provenance and reproducibility |

## Suggested opening

“A textbook gives you a picture of a system. What-If Lens makes it executable. Meta reads the material into a scientific model; specialist solvers calculate what happens when you change it.”

## Closing
